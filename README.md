# DXH Mafia

Public website for an independently initiated Daoxianghu fellowship, founded by Jiace Zhao.

Static HTML, CSS, and JavaScript. No build step or backend. Published with GitHub Pages from `main`, repository root.

- `index.html`: Chinese and English content, fellowship charter, Jiace's portrait and introduction.
- `style.css`: responsive monochrome layout.
- `app.js`: optional language preference stored locally.
- `assets/jiace-zhao.jpg`: portrait from Jiace's personal website.

Contact links point to Jiace's public personal website; no information is submitted automatically. Research resources are offered through personal connections, not institutional sponsorships.

Personal biography and portrait source: https://www.jc-zhao.com/.
